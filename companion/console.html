This https page reaching a local bridge is browser-restricted: Safari blocks it outright, and Chrome holds the request until you approve a "local network access" permission prompt by the address bar. The reliable way: open the console the bridge itself serves — http://localhost:8787/ — same origin, zero setup, token auto-filled. On a phone, "localhost" is the phone itself — use the API-key provider there instead.
